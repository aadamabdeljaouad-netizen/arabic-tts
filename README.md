# Arabic Text-to-Speech Web Application (`arabic-tts`)

An open-source, light-weight Arabic Text-to-Speech web service using Flask and Piper TTS (`ar_JO-kareem-low`). Optimized for deployment on free cloud providers such as Render.com.

## Features
- Natural Arabic speech generation via Piper TTS.
- Optimized ONNX Runtime thread & memory allocation.
- Fully responsive Web UI in Arabic.
- Direct WAV download & audio playback in browser.

## Deployment on Render
1. Connect this repository to Render.
2. Select **New -> Blueprint**.
3. Render will deploy using `render.yaml`.
